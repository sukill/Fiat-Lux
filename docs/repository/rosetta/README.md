# Domain: Rosetta (High Level Design Translation)

본 디렉토리는 비개발자(사업/기획)와 개발자 간의 언어적 간극을 좁히고, 비즈니스 요구사항을 기술적 설계로 정확히 번역하기 위한 **High Level Design(HLD) 가이드라인**을 관리합니다.

## 🎯 목적
- 비즈니스 언어와 기술 언어의 상호 해독(Deciphering).
- 상호 오해 없는 기능 명세 및 합의 프로세스 구축.
