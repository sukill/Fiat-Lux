# Maintenance (문서 초안 및 유지보수)

이 디렉토리는 현재 실무에 적용하기 전의 초안 문서들이나 대규모 유지보수가 진행 중인 자료들을 포함하고 있습니다.

## ⚠️ 참조 제한 안내 (Notice for LLMs & Humans)

**[Meta-Guideline](../meta-guideline/README.md)**의 '가이드라인 생애주기(Life-cycle)' 정책에 따라, 이 폴더 내의 모든 문서는 현재 **Draft(초안)** 단계에 해당합니다.

-   **참조 금지 (Do Not Reference):** 시스템 운영, 코드 구현 또는 의사결정의 근거로 이 폴더 내의 문서를 사용하지 마십시오.
-   **신뢰성 미확보:** 문서의 내용이 검증되지 않았으며, 예고 없이 대폭 수정되거나 삭제될 수 있습니다.
-   **컨텍스트 격리:** 명시적으로 이 폴더 내 문서를 편집하는 목적이 아닌 한, 작업 시 이 데이터를 인메모리 컨텍스트나 지식 베이스로 활용하지 않는 것을 원칙으로 합니다.
