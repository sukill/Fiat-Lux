# Documentation Index: Fiat-Lux Knowledge Base

본 디렉토리는 시스템의 개발, 운영 및 확장을 위한 모든 가이드라인과 기술 문서를 관리합니다.

---

## 🏗️ 문서 구조 및 목적

이 프로젝트의 문서는 **인간의 개입을 10%로 제한**하고, **시스템의 자율적 진화**를 지원하도록 설계되었습니다.

1.  **[Meta-Guideline](./meta-guideline/README.md):** 
    *   가이드라인의 가이드라인 (시스템의 헌법).
    *   문서의 규격, 생성 프로세스, 진화 알고리즘 정의.
2.  **[Repository](./repository/README.md):** 
    *   도메인별 구체적인 가이드라인 저장소 (Project 레벨).
    *   비즈니스 정렬(`Rosetta`) 등 실무 실행 지침 포함.
3.  **[Maintenance](./maintenance/README.md):** 
    *   현재 개발 중이거나 유지보수가 필요한 문서들의 임시 저장소.
    *   검토 중인 정책 등이 포함됩니다.

---

## ✍️ 공통 문서 작성 원칙 (General Guidelines)

모든 문서는 LLM 에이전트가 즉시 해석하고 실행할 수 있는 수준으로 작성되어야 합니다.

1.  **LLM 친화적 구조:** 기계가 파악하기 쉬운 헤더(` #`, `##`, `###`) 및 리스트 구조를 사용합니다.
2.  **상호 참조(Linkage):** 문서 간 연결은 명확한 상대 경로[`[텍스트](./경로.md)`]를 통해 관계를 형성합니다.
3.  **실행 가능성:** 추상적인 논의보다 실제 'Logic', 'Workflow', 'Schema' 중심의 지침을 기술합니다.
4.  **문서 식별:** 모든 주요 가이드라인은 고유 ID와 버전을 명시하여 추적이 가능하도록 합니다.
