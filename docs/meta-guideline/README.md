# Meta-Guideline: 가이드라인의 가이드라인

본 디렉토리는 Fiat-Lux 시스템의 핵심이자 가이드라인의 가이드라인인 **4대 핵심 문서 체계(Meta-Guideline)**를 관리합니다. 

여기서 정의된 규칙에 따라 프로젝트의 모든 하위 지침들이 생성, 운영, 진화됩니다. (상위 원칙은 [전체 README](../README.md)를 참고하세요.)

## 💡 핵심 운영 원칙

1.  **LLM을 독자로 생각하라:** 모든 문서는 LLM이 즉시 이해하고 실행할 수 있도록 구조화되어야 합니다.
2.  **최소한으로 시작하라 (Lean):** '규칙을 만드는 규칙'에 집중하고, 구체적인 사례는 시스템이 실무를 수행하며 채워나가도록 합니다.
3.  **정책 중심의 개입:** 인간은 코드의 세세한 부분을 수정하기보다 상위 수준의 가이드라인(정책)을 정하는 데 리소스를 집중합니다.

## ✍️ Meta-Guideline 관리 규칙

이 디렉토리 내 문서를 수정하거나 새로운 메타 가이드라인을 추가할 때의 세부 규칙입니다.

1.  **파일명 컨벤션:** `번호_주제.md` 형식을 엄수합니다 (예: `01_foundation.md`).
2.  **엄격한 계층 구조:** [Foundation](./01_foundation.md)에서 정의한 YAML 스키마와 계층 구조를 반드시 준수합니다.
3.  **데이터 중심:** 규칙 설명 시에는 가능한 YAML/JSON 등 구조화된 예시를 포함합니다.
